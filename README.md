# פרויקט QA: Streaming Platform Case Study

Portfolio site presenting an independent, end-to-end manual QA cycle on a video-streaming platform (web and mobile) by Meir Yaakovi.

- 301 test cases, 12 testing disciplines, 54 defects traced 1:1 to Jira
- Release decision (NO-GO) based on criteria defined before results
- Full 90-page Software Test Report (PDF) included

Live site (once public): https://meiryaakovi.github.io/streaming-qa/

Independent, unofficial, educational project. Not affiliated with or endorsed by the service under test or its owner. Trademarks belong to their respective owners. Security-category defects are redacted.

Plain HTML/CSS/JS, no build step.
