The decision

A release decision defined up front

Go / No-Go criteria were fixed before analyzing results, so the verdict follows the data rather than the other way round.

RELEASENO-GO

Why: one Show-Stop and six Critical defects are open.

  • GO Zero open defects at Show-Stop or Critical severity.
  • CONDITIONAL Open defects only at Major or below, with documented workarounds.
  • NO-GO Any open defect at Show-Stop or Critical severity.

Primary blocker: profile PIN recovery that never sends its verification email. The areas with the most bugs were not the areas carrying the most release risk. That gap is the real finding.

How it was done

Method & coverage

Manual, hands-on testing on desktop Chrome and a real Android device, with confirmatory passes on Firefox and Brave.

  1. Design

    Test cases written per feature area and prioritized, all kept in one master Excel workbook (the STD).

  2. Execute

    259 cases on Windows + Chrome, 29 on a Samsung Galaxy A56, the rest across other environments.

  3. Report

    Each failure logged as one Jira defect with severity, steps, expected vs actual and evidence.

  4. Decide

    Results judged against the Go / No-Go criteria set in advance, then summarized in a formal report.

  • UI/UX

Findings

Defects worth a closer look

A selection from the 54 logged defects. Security-category defects are intentionally left out of this public page.

NF-041 · Account ManagementShow-Stop

PIN recovery sends no verification email

Steps
Start PIN recovery for a protected profile.
Expected
A verification email arrives.
Actual
Nothing is ever sent. The flow dead-ends and blocks release.
NF-124 · Account ManagementCritical

No rate limiting on PIN entry

Steps
Enter a wrong PIN 50 times in one minute.
Expected
Lockout, challenge or alert.
Actual
All 50 attempts accepted with no delay. A four-digit code has only 10,000 combinations.
NF-290 · Discovery & SearchCritical

Search history leaks across profiles

Steps
Click the search bar.
Expected
Only the active profile's searches.
Actual
Searches from a different profile were visible.
NF-197 · InfrastructureCritical

Player unusable at 500% zoom

Steps
Zoom the browser to 500%.
Expected
Content reflows to one column.
Actual
Overlapping elements make the player unusable for low-vision users. WCAG 2.1 Reflow failure.
NF-196 · InfrastructureCritical

Total session loss after browser update

Steps
Force a browser update during playback.
Expected
Session and position resume after restart.
Actual
Session lost, movie progress not saved.
NF-301 · Streaming InterfaceMajor

Player UI stuck over a video call

Steps
Answer a WhatsApp video call during playback, then end it.
Actual
Playback pauses, but the player UI stays as an overlay on the call screen.
NF-300 · Streaming InterfaceModerate

Player state lost after a call ends

Actual
After hanging up a WhatsApp call, the app drops back to the details screen. The viewer has to find the title and press play again.
